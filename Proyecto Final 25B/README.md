Este repositorio está destinado para la entrega del proyecto final de análisis y algoritmos

El proyecto tiene como objetivo la realización de un programa que implemente técnicas de divide y venceros, 
programación dinámica y técnica voraz. En este caso estas técnicas fueron destinadas a un programa que se
encarga de la comprensión de imágenes. Para divide-vencerás y programación dinámica se utiliza un algoritmo
basado en QuadTree mientras que para la técnica voraz se utiliza la codificación de Huffman. 


En la carpeta src se encontrarán carpetas con los códigos de Python mientras que en la carpeta img se encontrarán
las capturas de los resultados, gráficas o comparativas.


Primeramente, descargue todo el contenido y ejecute el main.py


Dentro del programa suba una imagen en el apartado “Configuración” despues de hacer esto y en este mismo apartado
configure el método y las variables para la comprensión; Ya sea seleccionado el algoritmo de QuadTree y el nivel de
comprensión o la codificación de Huffman y una variable de error.


Al final el programa entregará tanto gráficas de complejidad temporal y espacial, asi como los resultados de las
imágenes en la carpeta raíz del proyecto. Si desea iniciar nuevamente pulse el botón “Limpiar todo” o cierre y abra
el programa.
